# FiestaSoft - Sistema Integral de Gestión Comercial y Ventas

Aplicación desarrollada para la administración comercial de un negocio, centralizando operaciones de ventas, compras, catálogo y control de entidades. Trabajo práctico desarrollado para la cátedra de Programación III (UTN - FRGP).

## 🚀 Módulos y Funcionalidades
- Gestión de Ventas: Registro de transacciones, consulta de historial, cálculo de totales y visualización del detalle por operación.
- Gestión de Compras: Registro de adquisiciones y seguimiento de movimientos.
- Catálogo de Productos: Administración integral de inventario (artículos, marcas y categorías).
- Gestión de Entidades: Control y seguimiento de Clientes y Proveedores con información de contacto y documentación (DNI/CUIT, email).
- Seguridad: Control de acceso y cierre de sesión de usuarios.

## 🛠️ Tecnologías y Arquitectura
- Backend / Lógica: C# (.NET), ASP.NET Web Forms, Arquitectura en capas (Dominio, Negocio, Datos).
- Frontend: HTML5, CSS3.
- Persistencia: SQL Server / ADO.NET.
